# Alauda Container Platform Distributed Tracing Lifecycle Policy

## Version Lifecycle Timeline

Below is the life cycle schedule for released versions of `Alauda Container Platform Distributed Tracing`:

| Version  | Release Date  | End of Support  |
| -------- | ------------- | --------------- |
| v2.0.z   | 2026-04-21    | 2027-10-21      |
| v2.1.z   | 2026-09-11    | 2028-03-11      |

## Release Policy

A new version of `Alauda Container Platform Distributed Tracing` is released every 4 months.

## Maintenance Policy

Alauda provides 18 months of maintenance support for each released version of `Alauda Container Platform Distributed Tracing`.

During the maintenance period, Alauda will provide the following services to customers:

1. Track the patch versions and promptly provide patches containing bug fixes and security updates.
2. Provide security updates that comply with Alauda's security standards.
3. Assist customers in smoothly upgrading to new versions.
